Important Notes
  • Only previous months' data can be backed up.
  • Current month's data cannot be backed up.
  • Backing up will create a ZIP file containing all form data and uploaded files.
  • After downloading the backup, all related data will be permanently deleted from the system.
  • When restoring a backup:
    • Only valid backup ZIP files can be restored
    • Forms with IDs that already exist will be skipped
    • All form data and uploaded files will be restored
    • The restore process is atomic - if any error occurs, no changes will be made
